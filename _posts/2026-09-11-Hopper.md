## Streaming Multiprocessor（SM）流式多处理器

SM 是 GPU 的基本计算单元。每个 SM 拥有独立的寄存器文件、共享内存/L1 缓存，以及一套完整的 Warp 调度器和功能单元。

- Occupancy（占用率）

| 有限资源     | 说明                                                      |
| ------------ | --------------------------------------------------------- |
| 寄存器       | 每个线程用的寄存器越多，SM 能同时容纳的线程（Warp）就越少 |
| 共享内存     | 每个线程块申请的共享内存越多，SM 能同时容纳的线程块就越少 |
| 线程块数上限 | SM 对同时驻留的线程块数量有硬件上限                       |

## Warp 线程束

Warp 是 SM 调度和执行的基本单位。SM 不是逐线程调度指令，而是以 Warp 为粒度——每个调度周期，Warp 调度器挑选一个就绪的 Warp，向其中所有线程同时发射同一条指令。

在 NVIDIA GPU 中，一个 warp 通常包含 32 个 thread。同一个 wrap 中的 thread 会以 SIMT（Single Instruction, Multiple Thread）的方式执行指令。

- Warp 之间的切换是零开销的。

> [!NOTE]
>
> 一个 SM 可以同时驻留多个 Thread Block
>
> 但是一个 Thread Block 只能在一个 SM 上运行，不能跨多个 SM
